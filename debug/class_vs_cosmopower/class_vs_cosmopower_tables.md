## Findings (hand-written, 2026-10-05; not regenerated by the script)

- Reference: class_public HEAD 64bbab7 (v3.4.0), built from source. Identical C sources to the PyPI classy 3.4.0.1.
- CosmoPower is systematically LOW in the damping tail: TT -0.2% at l=1000, -0.7% at l=2000-2500; EE similar (-0.3 to -1%).
  Up to ~0.4 sigma_CV per multipole at l>1600. Low/mid l (<800) agrees to <0.05% (TT).
- Not a CLASS version or precision effect: vs CLASS v2.9.4 (2021, contemporary with the CosmoPower paper) the TT deficit is
  still -0.55% at l=2000; changing l_max_scalars, k_max_tau0_over_l_max, accurate_lensing does not move it; massive neutrinos
  or halofit/HMcode make the agreement worse. Most likely emulator error (very wide training box: omega_cdm 0.001-0.99, h 0.2-1).
- Size of the effect, chi2 = -2 ln L of CosmoPower spectra against CLASS spectra as fiducial (TT+TE+EE Wishart):
    cosmic variance only, f_sky=1:          l 2-29: 1.2 | 30-799: 3.4 | 800-1599: 24.7 | 1600-2508: 211 | total 240
    fake_planck_realistic noise, f_sky=0.57: l 2-29: 0.2 | 30-799: 0.6 | 800-1599: 3.8  | 1600-2508: 1.0 | total 5.6
- Relevance for the omega_m bins: the TT deficit over l=1600-2508 is matched by a shift Delta omega_m ~ +0.001 in that bin
  (d ln C_l^TT / d omega_m ~ -4.1 there, other parameters fixed). Harmless for mock data generated by the emulator itself
  (the error cancels); a potential spurious high-l omega_m shift on REAL Planck data.

## ell-indexing audit (2026-10-05)

- Alignment fit (table above): best shift |d| <= 0.27 for TT/TE/EE; d = 0 beats d = +-1 everywhere. Negative control: shifting the
  stand-in output by +1 / +2 multipoles is recovered as d = -1.03 / -2.03 and flagged FAIL, so the test catches index bugs.
  The residual |d| ~ 0.1-0.3 at high l is a tiny peak-position (acoustic-scale) difference between the CAMB-trained emulator and CLASS.
- MontePython end-to-end: fake_planck_realistic fiducial files written by MontePython with real CLASS and with the stand-in have
  identical ell columns (2..2508); (stand-in file - CLASS file) equals (stand-in C_l - CLASS C_l) at the same l to 1e-6
  (the files' 8 significant figures).
- Likelihood cross-check: MontePython -lnL of stand-in theory against a real-CLASS fiducial = 2.866 (chi2 = 5.73), matching
  the standalone estimate (5.6). Lensing extraction adds only 0.0004.
- classy.py hardened: import fails if the emulator ell grid is not every integer 2..2508; compute() fails if the l_switch bins
  leave any multipole uncovered (previously would have been uninitialised memory).
